# 用 RAG 改造团队知识库的 5 个实践

很多团队已经积累了文档、会议纪要和代码片段，但真正需要答案时，信息仍然分散在不同工具里。

## 1. 先收敛知识源

- 优先选择高频访问的产品文档、FAQ 和技术方案。
- 给每条文档保留来源、更新时间和负责人。

## 2. 切分策略要能解释

文档切分不只是固定长度。技术内容可以按照标题、列表和代码块分段。

```ts
type KnowledgeChunk = {
  title: string;
  source: string;
  content: string;
};
```
