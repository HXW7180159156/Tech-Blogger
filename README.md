# Tech Blogger MVP Demo

一个可本地运行的技术博客写作 APP 最小演示闭环：导入 Markdown 技术文章，编辑内容，执行离线模拟的 AI 辅助动作，并导出微信公众号、小红书、抖音三类平台稿件。

## 运行步骤

### 环境要求

- Python 3：用于启动本地静态文件服务。
- Node.js：用于执行 JavaScript 语法检查。
- 不需要安装 npm / pnpm 依赖；当前 MVP 是无构建步骤的静态页面。

1. 在仓库根目录启动静态服务：

   ```bash
   python3 -m http.server 5173
   ```

2. 浏览器打开：

   ```text
   http://localhost:5173
   ```

3. 按页面中的演示流操作：
   - 点击“载入示例文章”导入内置 Markdown。
   - 在编辑区调整标题与正文。
   - 使用“生成摘要”“优化标题”“生成平台改写”完成辅助处理。
   - 选择微信公众号 / 小红书 / 抖音模板并复制导出结果。

## 开发、测试和检查流程

当前仓库没有 package manager 配置、自动化测试套件或打包产物；以下命令是已验证可用的最小流程。

### 本地运行

```bash
python3 -m http.server 5173
```

浏览器打开 `http://localhost:5173` 后，按页面上的“载入示例文章 -> 生成摘要/优化标题/生成平台改写 -> 选择平台模板 -> 复制导出结果”完成端到端验证。

### 语法检查

```bash
node --check src/app.js
```

### 静态页面可访问性检查

在另一个终端保持本地服务运行后执行：

```bash
curl -fsS http://localhost:5173/ | grep -q "Tech Blogger MVP Demo"
```

### 构建

当前无需构建。`index.html`、`styles.css` 和 `src/app.js` 可直接作为静态资源提供服务。

### 自动化测试

当前尚未接入自动化测试框架。修改交互逻辑时至少执行 `node --check src/app.js`，并按“本地运行”步骤手动验证完整 demo 闭环。

## 当前闭环

- 支持粘贴或载入 Markdown 文本。
- 自动识别标题、段落、列表、代码块等基础结构并展示预览。
- 提供 3 个离线 AI 辅助动作，便于无 API key 环境下演示。
- 一键生成三类平台稿件：
  - 微信公众号：长文结构、导语、目录感、代码块保留。
  - 小红书：标题、短段落、要点、标签。
  - 抖音：口播脚本、分镜提示、结尾互动。
- 支持复制导出内容到剪贴板。

## 已知限制

- AI 能力为本地规则模拟，暂未接入真实模型 API。
- Markdown 渲染仅覆盖演示所需的标题、段落、列表、代码块和内联代码。
- 不包含账号授权、平台自动发布、图片排版或视频生成。

## 下一步建议

1. 接入真实 LLM 服务，让摘要、标题和平台改写基于模型生成。
2. 增加 Markdown 文件上传、导出 `.md` 文件和微信公众号 HTML 复制模式。
3. 引入持久化草稿、版本历史和更多平台模板。

## 协作注意事项

- 先保持无后端、无构建的静态 MVP 可运行，再引入框架、构建链或外部 API。
- 新增依赖时同步提交依赖清单和锁文件，并在本节更新安装、运行、检查和测试命令。
- 平台导出模板变更需要覆盖微信公众号、小红书、抖音三类输出，避免只验证单个平台。
- AI 相关能力目前是离线规则模拟；接入真实模型前不要在代码或文档中提交 API key、token 或账号凭据。
