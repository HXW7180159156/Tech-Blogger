# Tech Blogger

一个无依赖静态 MVP，用来把同一篇技术文章导出为微信公众号、小红书和抖音三个平台的可发布草稿。

## 功能范围

- 平台模板配置：内置微信公众号、小红书、抖音模板，覆盖排版风格、标题规则、摘要规则、标签建议、代码块处理和图片比例建议。
- 导出格式：
  - 微信公众号：HTML / 富文本结构，保留标题、摘要、标签、正文层级和代码块。
  - 小红书：图文卡片结构，自动生成封面卡、正文卡、代码卡和话题标签。
  - 抖音：短视频文案 / 脚本结构，生成 3 秒钩子、分镜口播、代码镜头和收尾 CTA。
- 模板预设管理：页面内可调整当前模板字段；内置配置集中在 `src/app.js` 的 `builtInTemplates`，后续可扩展为远端模板、团队模板或 JSON 配置。

## 本地运行

无需安装依赖，直接用任意静态服务打开即可：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 使用方式

1. 点击“载入示例文章”，或手动填写标题、摘要、标签、配图提示和 Markdown 正文。
2. 在“模板预设管理”中选择平台，按需调整排版风格、标题/摘要/标签规则、代码块处理和图片比例。
3. 点击“一键生成三平台草稿”，页面会同步生成微信公众号 HTML/富文本、小红书图文结构和抖音文案/脚本结构。
4. 使用每个输出卡片右下角的“复制草稿”按钮复制对应平台内容。

## 扩展点

- 把 `builtInTemplates` 抽成 JSON 配置，支持团队级模板预设。
- 为微信公众号导出接入代码高亮、主题 CSS 和图床上传。
- 为小红书导出接入长图切片、封面模板和敏感词检查。
- 为抖音导出接入字幕 SRT、分镜表和 TTS 配音。
- 增加 Markdown / Word / HTML 导入适配器后，可复用当前统一文章模型生成平台草稿。
